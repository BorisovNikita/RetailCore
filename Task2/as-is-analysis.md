## 2. Анализ PlantUML-диаграммы

**Что подтверждено:**
- Java-монолит - центральный компонент обработки заказов.
- Oracle - операционная БД, интеграционный слой и часть бизнес-логики.
- Наличие .NET integration service и Python analytics jobs.
- Async / batch exchange для асинхронных операций.
- Admin / Support tools для ручных операций.
- Внешние партнёры: маркетплейсы, платёжные провайдеры, службы доставки.

**Что диаграмма не отражает:**
- Фактические обходные маршруты и временные решения.
- Смешанные способы интеграции (REST, очереди, таблицы, batch).
- Скрытые зависимости через staging/shared tables.
- Распределение бизнес-логики по Oracle-процедурам.
- Проблемы дедупликации и идемпотентности.
- Реальные потоки данных аналитики.
